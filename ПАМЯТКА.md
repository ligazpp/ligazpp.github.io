# Памятка: как работать с сайтом

Это исходники сайта **ligazpp.github.io** («Лига защитников потребителей»).

## Как всё устроено (простыми словами)

**Репозиторий** — это папка проекта, которая живёт в двух местах сразу: на GitHub (в облаке) и на вашем компьютере (папка `ligazpp`). Вы меняете файлы на компьютере и нажимаете «Sync» — копия меняется и на GitHub. История всех изменений тоже хранится.

**GitHub Pages** — бесплатный хостинг. Правило: если репозиторий называется `ligazpp.github.io`, GitHub открывает сайт по адресу **https://ligazpp.github.io**.

Как сайт обновляется:

```
[1] Вы правите исходники в VS Code (папка src/)
        ▼
[2] Commit + Sync  → файлы уходят в репозиторий ligazpp.github.io
        ▼
[3] GitHub «робот» (Actions) сам собирает сайт
        ▼
[4] GitHub Pages выкладывает готовый сайт
        ▼
[5] Люди видят: https://ligazpp.github.io
```

Шаги 2–4 делаются сами. Ваша работа: поправить → Sync → подождать ~1 минуту.

**Главное правило**

- Редактируйте файлы **только в папке `src/`**.
- Папку `_site/` и `node_modules/` не трогайте — это сборка и вспомогательные файлы, их создаёт программа.

## Как посмотреть сайт у себя на компьютере (перед публикацией)

1. В VS Code откройте терминал (Ctrl + `).
2. Выполните `npm run dev`
3. Откройте в браузере http://localhost:8080
4. Закрыть предпросмотр — нажмите Ctrl + C в терминале.

## Как опубликовать изменения на сайте

1. После правок нажмите **Cmd + S** (сохранить).
2. Слева нажмите иконку **Source Control** (ветки).
3. Видите список изменённых файлов — это нормально.
4. Впишите сообщение (например «обновил контакты») и нажмите **Commit**.
5. Нажмите **Sync Changes** (синяя кнопка).
6. Подождите ~1–2 минуты — сайт обновится сам.

## Где лежат ваши тексты

- Статьи и материалы: `src/articles/*.md` — каждый файл `.md` — это одна статья.
- Тексты разделов (Начало, О нас, Контакты): `src/*.njk`.
- Внешний вид: `src/style.css`.
- Поведение (меню, кнопки): `src/script.js`.
- Контакты, реквизиты, соцсети: `src/_data/site.json`.

## Как проверить, что всё опубликовалось

- Откройте на GitHub репозиторий **ligazpp/ligazpp.github.io** → вкладка **Actions**.
- Если последняя сборка зелёная (галочка) — сайт обновлён.
- Ключевая страница: https://ligazpp.github.io

## Что стало со старым адресом zppliga.github.io/mysite

Раньше сайт жил на платном домене `ligazpp.ru`. Когда его отключили за неоплату, мы временно открыли сайт по адресу `zppliga.github.io/mysite` (это резервная копия на старом аккаунте `zppliga`). Затем сайт переехал на постоянный бесплатный адрес `ligazpp.github.io` (аккаунт/организация `ligazpp`).

Сейчас `zppliga.github.io/mysite` — это старая, больше не обновляемая копия. Она никому не мешает и может служить резервом, но её можно и удалить. Рабочий адрес всегда один: **https://ligazpp.github.io**.
