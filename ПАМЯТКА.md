Адрес сайта: **https://ligazpp.github.io**

Подсказка про размер шрифта в VS Code: нажмите **Cmd +** (удерживая Cmd, нажимайте «плюс»), чтобы увеличить всё в окне. Вернуть обратно — **Cmd −**.

---

## Что это такое (коротко)

- **VS Code** — программа, в которой правятся тексты и настройки сайта.
- **Репозиторий** — папка проекта, которая живёт сразу в двух местах: на вашем компьютере (папка `ligazpp`) и на GitHub. Они постоянно синхронизируются.
- **GitHub Pages** — бесплатный хостинг: именно он показывает сайт в интернете.

**Весь рабочий цикл:** правите → «Sync» → подождали ~1 минуту → сайт обновился.

---

## Как всё устроено

У вас на GitHub есть **аккаунт `zppliga`** — это ваш вход и «хозяин» всего. Внутри аккаунта создана **организация `ligazpp`** — отдельный кабинет под сайт.

В этой организации живёт **один репозиторий:** `ligazpp.github.io`. В нём хранятся исходники сайта.

GitHub Pages работает по простому правилу: репозиторий с именем `что-то.github.io` автоматически открывается по адресу `что-то.github.io`. Поэтому наш сайт живёт на **https://ligazpp.github.io**.

Важно: в репозитории лежат **исходники** (тексты, стили, настройки), а не готовые страницы. Готовый сайт GitHub собирает сам, автоматически, с помощью «робота-сборщика» (Acutions). Руками ничего собирать не надо.

**Схема работы:**

- шаг 1 — вы правите тексты в VS Code (папка `src`)
- шаг 2 — «Commit + Sync» отправляет изменения на GitHub
- шаг 3 — «робот» сам собирает сайт из исходников
- шаг 4 — GitHub Pages выкладывает готовый сайт
- шаг 5 — люди открывают https://ligazpp.github.io

Шаги 2–4 выполняются автоматически. Ваша работа — только шаг 1.

## Как опубликовать изменения

### Способ 1 — кнопками (самый простой)

1. Сохраните правки: **Cmd + S**.
2. Слева нажмите иконку **Source Control** (тройная веточка).
3. Проверьте, что ваши файлы видны в списке Changes.
4. Впишите сообщение (например: «обновил статью») и нажмите **Commit**.
5. Нажмите **Sync Changes**.
6. Через 1–2 минуты сайт обновится.

### Способ 2 — командами в терминале VS Code

Откройте терминал: **Terminal → New Terminal** (или клавиши Ctrl + `). Затем по порядку:

`git status` — показать, какие файлы изменены

`git add .` — отметить все изменения

`git commit -m "что я изменил"` — сохранить снимок (свой текст в кавычках)

`git push` — отправить на GitHub (публикация запустится сама)

Если `git status` показывает пустой список — вы правили не тот файл. Правки нужно делать в папке `src`, а не в `_site`.

## Предпросмотр на компьютере

Перед публикацией можно посмотреть сайт у себя, не трогая GitHub. В том же терминале:

`npm run dev`

Затем откройте в браузере **http://localhost:8080**.

Остановить предпросмотр: нажмите **Ctrl + C**.

## Где лежат ваши тексты

- `src/articles` — статьи и материалы (один файл — одна статья)
- `src` — тексты разделов: Начало, О нас, Контакты, меню
- `src/style.css` — внешний вид: цвета, шрифты, отступы
- `src/script.js` — поведение: мобильное меню, кнопки
- `src/_data/site.json` — контакты, реквизиты, соцсети

Главное правило: **правим только папку `src`.** Папки `_site` и `node_modules` не трогаем — их создаёт программа.
