# Памятка: как работать с сайтом

Это исходники сайта **ligazpp.github.io** («Лига защитников потребителей»).

## Главное правило

- Редактируйте файлы **только в папке `src/`**.
- Папку `_site/` и `node_modules/` не трогайте — это сборка и вспомогательные файлы, их создаёт программа.

## Как посмотреть сайт у себя на компьютере (перед публикацией)

1. В VS Code откройте терминал (Ctrl + `).
2. Выполните `npm run dev`
3. Откройте в браузере http://localhost:8080
4. Закрыть предпросмотр — нажмите Ctrl + C в терминале.

## Как опубликовать изменения на сайте

1. После правок нажмите **Cmd + S** (сохранить).
2. Слева нажмите иконку **Source Control** (ветки).
3. Видите список изменённых файлов — это нормально.
4. Впишите сообщение (например «обновил контакты») и нажмите **Commit**.
5. Нажмите **Sync Changes** (синяя кнопка).
6. Подождите ~1–2 минуты — сайт обновится сам.

## Где лежат ваши тексты

- Статьи и материалы: `src/articles/*.md` — каждый файл `.md` — это одна статья.
- Тексты разделов (Начало, О нас, Контакты): `src/*.njk`.
- Внешний вид: `src/style.css`.
- Поведение (меню, кнопки): `src/script.js`.
- Контакты, реквизиты, соцсети: `src/_data/site.json`.

## Как проверить, что всё опубликовалось

- Откройте на GitHub репозиторий **ligazpp/ligazpp.github.io** → вкладка **Actions**.
- Если последняя сборка зелёная (галочка) — сайт обновлён.
- Ключевая страница: https://ligazpp.github.io
