## Как это работает?

Файл с расширением `.md` — это обычный текст с небольшими «значками». При сборке сайта текст превращается в страницу автоматически: значок `##` становится заголовком, `**слово**` — жирным, строка с `- ` в начале — пунктом списка.

Одна статья = один файл в папке `src/articles`. Имя файла определяет адрес: `markdown-memo.md` откроется по адресу `/articles/markdown-memo/`.

## Почему .md удобнее других способов

**Главная выгода: разделение «содержания» и «оформления».**

Вы пишете **что** показать (`## Заголовок`, `- пункт`, `**важно**`), а **как** это выглядит — решает один файл стилей (`src/style.css`) сразу для всего сайта. Поэтому:

- **Одна правка стиля меняет все статьи.** Сдвинули отступ заголовков в `style.css` — обновились все статьи, законы и обзоры сразу.
- **Файл читается глазами.** В `.md` структура видна прямо в тексте: `##`, `**`, `- `. В Word границы абзацев, стили и жирность скрыты от глаз.
- **Вы не можете сломать вёрстку.** Невозможно случайно поставить шрифт 8px или гигантский отступ — оформление можно менять только через стили, а там значений немного.
- **Версии видны построчно.** `.md` — это текст; если сравнить две версии, видно, какие строки добавили, а какие удалили. У `.docx` это бинарный файл.
- **Дёшево и быстро.** Не нужна база данных и CMS: файл → страница. Сайт остаётся статическим и работает бесплатно на GitHub Pages.

Сравнение с другими «способами залива» статей:

- **Word (`.docx`)** — хранит «застывшее» форматирование, которое не подстраивается под общий стиль сайта (именно поэтому и задуман конвейер Word → `.md`).
- **Готовый HTML** — можно, но громоздко: `<h3 style="…">` вместо короткого `###`.
- **CMS/конструктор (WordPress, Tilda)** — тут не подходят: нужен хостинг с базой данных, а сайт статический.

## Как формируется список «Статьи» (важно!)

Страница «Статьи» (`src/articles.njk`) — это **не** «покажи все файлы из папки». Это обычная HTML-страница, где карточки **написаны вручную**, одной на каждую статью:

```
<!-- Статья 1 -->
<div class="card card--article">
    <h2>Как вернуть некачественный товар?</h2>
    <p>Пошаговая инструкция: …</p>
    <a href="/articles/return-goods/">Подробнее</a>
</div>
```

При сборке сайт **не смотрит на папку** `src/articles` — он просто выводит то, что написано в шаблоне. Поэтому новая статья:

- **появляется** отдельной страницей (например `/articles/my-new-article/`);
- **не появляется** в списке «Статьи», пока в `articles.njk` не добавят карточку вручную.

Решение — «коллекция» (автогенерация): шаблон просит у сборщика «все файлы из `src/articles`» и рисует карточки сам. Тогда добавлять карточки вручную не нужно.

## Как значок ## находит свой стиль

Три шага происходят автоматически при сборке.

**Шаг 1. Значок `.md` → HTML-тег** (это делает сборщик Eleventy с движком markdown-it):

| Пишете | Получается HTML |
|---|---|
| `## Заголовок` | `<h2>Заголовок</h2>` |
| `### Подзаголовок` | `<h3>Подзаголовок</h3>` |

Запомните: `##` — это **h2** (крупный), `###` — **h3** (поменьше). Уровень заголовка = количество `#`.

**Шаг 2. HTML вкладывается в «обёртку» с классами.** Шаблон `article.njk` окружает весь текст так:

```
<article class="law-content article-content">
    {{ content | safe }}   ← сюда вставляется весь markdown после шага 1
</article>
```

**Шаг 3. CSS выбирает стиль по классам обёртки и тегу:**

```
.law-content.article-content h2 { font-size: 20px; … }
.law-content.article-content h3 { font-size: 16px; … }
```

CSS-правило читается так: «внутри блока с классами `law-content` и `article-content` найди элементы `h2` (или `h3`) и примени стиль». Никакой «догадки» нет — это жёсткая цепочка: **значок → тег → обёртка → стиль**.

Поэтому для `## Заголовок` сработает правило про `h2` (20px), а правило про `h3` (16px) — только на `###`.

## Шапка статьи (frontmatter)

Каждый файл начинается с шапки — трёх коротких строк между двумя `---`. Шапка сообщает сайту название и настройки:

```
---
layout: article.njk
title: "Название статьи"
subtitle: "Короткое описание под заголовком"
description: "Краткое описание для поисковых систем"
active: articles
---
```

Что означает каждое поле:

- `layout` — какой шаблон использовать. Для статей всегда `article.njk`, для текстов законов — `law.njk` (и тогда добавляются ещё поля `slug` и `active: zakon`).
- `title` — большой заголовок страницы.
- `subtitle` — строка-подзаголовок под ним. Поле необязательное.
- `description` — описание для поисковиков и карточек. Необязательное, но полезное.
- `active` — какой пункт меню подсветить («Статьи» или «Законодательство»).

Между шапкой и текстом обязательно оставляйте пустую строку.

## Заголовки

Заголовки — основная «скелетная» разметка. Чем больше `#`, тем мельче заголовок:

```
## Заголовок раздела
### Подзаголовок
```

На сайте `##` выглядит крупным синим заголовком, `###` — чуть меньше. Заголовки первого уровня `#` внутри статей не используйте — они зарезервированы под название страницы.

Из заголовков автоматически строится «Содержание» на страницах законов, поэтому называйте их коротко и понятно.

## Абзацы

Абзац — это просто непустые строки текста. Чтобы сделать новый абзац, оставьте между блоками пустую строку (Enter дважды):

```
Это первый абзац.

Это второй абзац.
```

Если просто переносите строку без пустой — текст склеится в один абзац.

## Выделение: жирный и курсив

```
**жирный текст**
*курсив*
```

`**две звёздочки**` — жирный, `*одна звёздочка*` — курсив. Одинарный `_` тоже даёт курсив.

## Списки

Маркированный список — каждая строка начинается с `- ` или `* `:

```
- первый пункт
- второй пункт
```

Нумерованный список — строки с цифрой и точкой:

```
1. первый шаг
2. второй шаг
```

Номера проставлять не обязательно — сайт сам пересчитает. Между пунктами пустая строка не нужна. Вложенный список — два пробела в начале строки.

## Ссылки

```
[текст ссылки](https://example.com)
```

Открыть ссылку в новой вкладке прямо из Markdown нельзя — это настраивается в шаблоне. Если ссылка ведёт на другую страницу сайта, удобно писать её коротко: `[Закон о защите прав потребителей](/zakon/zpp/)`.

## «Якоря» — ссылка на раздел внутри страницы

У каждого заголовка автоматически появляется якорь — адрес-метка. Он позволяет ссылаться на конкретный раздел:

```
[Перейти к абзацам](#abzatsy)
```

На практике адрес якоря образуется из текста заголовка транслитом: `## Абзацы` → `#abzatsy`. Ссылка на раздел той же страницы выглядит как `[абзацы](#abzatsy)`. Чтобы узнать точный якорь, можно навести курсор на заголовок в браузере и посмотреть адрес.

## Разделитель

Три дефиса в отдельной строке рисуют горизонтальную линию:

```
---

```

## Цитаты

Строки, начинающиеся с `> `, оформляются как выделенная цитата:

```
> Важная мысль для выделения.
```

## Код (реже для статей)

Текст в «ёлочках» оформляется моноширинным шрифтом. Полезно, когда нужно показать образец документа или реквизиты:

```
Номер договора: 12345
```

## Картинки

```
![подпись (не видна на странице)](адрес-картинки)
```

Картинку нужно сначала положить в папку сайта (например `src/doc/`), а в скобках указать путь от корня: `![Логотип](/doc/logo.svg)`.

## HTML прямо внутри текста

Файл `.md` понимает и обычную HTML-разметку. Это самый гибкий приём: он используется в текстах законов для оформления судебных актов (например, чтобы выровнять строку с «Определением Судебной коллегии» особым стилем). Пример такого блока:

```
<div class="law-cite"><i class="fa-solid fa-circle-info"></i><div class="law-cite__text">Определение Судебной коллегии …</div></div>
```

На странице такой блок выглядит как аккуратная подпись справа внизу кейса. Обычному автору статей знать это не обязательно — достаточно просто не бояться, что HTML-файл «сломает» текст.

## Чего формат не умеет

- Таблиц нет — вместо них используйте списки или подзаголовки.
- Выравнивание картинок и текста по центру не поддерживается — это делается только стилями.
- Цвета, размеры шрифта, отступы в самом файле задать нельзя — за это отвечает единый стиль сайта (`src/style.css`).

## Готовый промт для нейросети (Deepseek)

Можно делегировать черновую статью нейросети, а потом поправить руками. Скопируйте промт ниже, вставьте вместо `{ТЕМА}` свою тему — и нейросеть вернёт готовый файл `.md`, который сразу кладётся в `src/articles`.

```
Ты — редактор общественной организации «Лига защитников потребителей».
Напиши статью для сайта лиги по теме: {ТЕМА}.

ФОРМАТ ВЫВОДА — строго Markdown, готовый файл для переноса на сайт:

---
layout: article.njk
title: "Название статьи"
subtitle: "Короткое описание под заголовком"
description: "Краткое описание для поисковых систем (1–2 предложения)"
active: articles
---

   (пустая строка, затем текст)

Правила оформления:
- Заголовки — только значки ## (раздел) и ### (подраздел). Один уровень № не использовать.
- Абзацы отделяются ПУСТОЙ строкой (Enter дважды).
- Жирный — **важные термины и выводы**, курсив — *акценты*.
- Списки — строки с "- " (маркированный) или "1. " (нумерованный) для шагов.
- Цитаты — строки с "> " для важных правовых мыслей.
- Внутри текста НЕ использовать таблицы, HTML-теги, картинки, смайлики.

СТИЛЬ: живой, дружелюбный, уверенный, понятный обычному человеку — без канцелярита и панибратства, без занудства. Объясняй сложное простыми словами.

СТРУКТУРА:
1. Короткое вступление — зачем читать.
2. ## разделы с полезными подзаголовками (используй ###).
3. Пошаговый алгоритм действий — что делать, куда обращаться, что говорить.
4. Учитывай, что продавец может отказывать или путать покупателя — заранее дай ответы на такие ситуации.
5. Списки и риторические вопросы.
6. Краткий мотивирующий вывод в духе: «закон на вашей стороне — Лига поможет».

ЦЕЛЬ: правовое просвещение и практическая помощь гражданам.
Объём — примерно 1000–1500 слов. Верни только сам файл .md без пояснений.
```

После генерации: скопируйте текст, сохраните в VS Code как `src/articles/имя-файла.md`, проверьте шапку и пустую строку после неё.

## Пять правил для быстрого старта

1. Один файл — одна статья, имя файла — латиницей.
2. Не забывайте шапку `--- layout/title/... ---` и пустую строку после неё.
3. Заголовки делайте через `##` и `###`, больше одного уровня не заходите.
4. Абзацы разделяйте пустой строкой.
5. После правок сохраните файл — сайт пересоберётся при следующей публикации.
