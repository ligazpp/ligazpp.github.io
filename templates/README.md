# Библиотека шаблонов сайта

Здесь хранятся готовые кусочки кода, которые можно переиспользовать на страницах сайта. Библиотека будет пополняться по мере работы.

## Содержимое

- **[macos-window/](macos-window/)** — окно в стиле macOS: полоска с тремя кружочками (красный/жёлтый/зелёный), заголовок, содержимое. Подходит для оформления разделов-«приложений»: служебные страницы, личные кабинеты, панели.

## Как добавлять шаблоны

1. Создайте папку с коротким нейтральным именем: `название-шаблона/`.
2. Положите готовый код: `*.css` (стили), `*.html` (разметка), при необходимости `*.md` с описанием.
3. Обновите список выше и кратко опишите, откуда шаблон и когда его применять.

## Как использовать шаблон

- Скопируйте нужную разметку на страницу и поправьте тексты.
- Подключите CSS: либо добавьте файл в сборку проекта, либо перенесите правила в `src/style.css`.
- Стили строятся на CSS-переменных проекта (`--color-*`, `--shadow-*`) — при переносе в другую тему проверьте, что переменные совпадают.
